# M6 — Измерение эффекта

Основание: [мини-ТЗ](../TZ/mini_TZ.md), [ТЗ §2–3](../TZ/TZ.md), [Business Vision](../business-vision.md). Связи: [архитектура](../architecture.md), [roadmap](../../ROADMAP.md).

**Бизнес-проблема:** Посещения, клики и установки смешиваются, экономический результат неизвестен.

**Решение:** Согласованная аналитика с consent, baseline и атрибуцией магазинов/MMP.

**Экономический эффект / KPI:** Оценка CAC, полезности FAQ и качества B2B; отказ от расходов без подтверждённого эффекта.

## FR

События: переход в магазин, открытие поддержки, отправка партнёру, просмотр статьи, поиск. Источник, store, placement и path без текста персональных обращений.

## NFR

Не блокировать переход в магазин; учитывать отказ согласия и потери событий; согласованные retention и доступ.

## DoD и статус

Есть только локальное wooppay:app-download. DoD: согласованный провайдер принимает тестовые события, проверена дедупликация по сессиям, отказ согласия и отчёт воронки; установки сверены с магазином.
