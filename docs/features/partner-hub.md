# M4 — Партнёрский домен

Основание: [мини-ТЗ](../TZ/mini_TZ.md), [ТЗ §2–3](../TZ/TZ.md), [Business Vision](../business-vision.md). Связи: [архитектура](../architecture.md), [roadmap](../../ROADMAP.md).

**Бизнес-проблема:** Первичный контакт требует ручной презентации.

**Решение:** HTML-страница /partners с возможностями, подтверждёнными сведениями и формой.

**Экономический эффект / KPI:** ≥5 доставленных валидных заявок/месяц к месяцу 6; экономия времени на презентациях. Выручку считать по квалификации и договорам.

## FR

Контент для банков, контакты, согласие, серверная валидация, сохранение заявки и доставка CRM/email с повтором.

## NFR

Доставка ≤1 минуты; защита от спама; идентификатор заявки и идемпотентность повторной отправки.

## DoD и статус

Запланировано. DoD: тестовая заявка сохранена, доставлена, повтор не создаёт дубль; сбой доставки не теряет заявку. PDF допустим дополнительно, но не заменяет HTML.
