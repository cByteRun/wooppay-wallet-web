# M3 — FAQ и инструкции

Основание: [мини-ТЗ](../TZ/mini_TZ.md), [ТЗ §2–3](../TZ/TZ.md), [Business Vision](../business-vision.md). Связи: [архитектура](../architecture.md), [roadmap](../../ROADMAP.md).

**Бизнес-проблема:** Поддержка тратит время на повторные вопросы.

**Решение:** FAQ с прямым ответом, отдельные страницы установки, условий и поддержки; дальше точные инструкции и поиск.

**Экономический эффект / KPI:** Цель −20% типовых обращений по мини-ТЗ (−15% в полном ТЗ). Экономия = предотвращённые обращения × среднее время обработки × стоимость минуты.

## FR

FAQ-хаб и адресуемые ответы; ссылки на источники, дату проверки и следующий шаг; поиск по статьям/FAQ; понятная эскалация при отсутствии ответа.

## NFR

Ответ в HTML, навигация с клавиатуры; финансовые сведения только из утверждённого источника.

## DoD и статус

Хаб и три FAQ-страницы реализованы. Поиск, полные сценарии и измерение снижения нагрузки остаются в milestone. Просмотр FAQ сам по себе не доказывает предотвращённое обращение.
