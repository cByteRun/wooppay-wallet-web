# M1 — SEO, AEO и GEO

Основание: [мини-ТЗ](../TZ/mini_TZ.md), [ТЗ §2–3](../TZ/TZ.md), [Business Vision](../business-vision.md). Связи: [архитектура](../architecture.md), [roadmap](../../ROADMAP.md).

**Бизнес-проблема:** Информационный спрос уходит конкурентам; нет единого цитируемого источника.

**Решение:** Серверный официальный контент по задачам пользователя, точные факты, навигация и метаданные.

**Экономический эффект / KPI:** 10 000 органических визитов/месяц к месяцу 6; первые брендовые позиции за 1–2 месяца, топ-10 по 3 согласованным запросам за 3–6 месяцев. Это цели, не гарантии.

## FR

HTML, уникальные title/description, canonical, OG/Twitter, sitemap и robots; стабильные сущности WebSite/MobileApplication; три адресуемых FAQ.

## NFR

Контент и ссылки доступны без JS; неизвестные FAQ возвращают 404; preview noindex.

## DoD и статус

Техническая часть реализована; проверки сборки обязательны. Производственный запуск и KPI ожидают домена, контента, аналитики и внешнего мониторинга.

## Паттерны и антипаттерны

| Паттерн | Антипаттерн |
| --- | --- |
| Прямой полезный ответ и оригинальный материал | Сотни однотипных страниц для вариаций ключа |
| SSG/ISR, серверные ссылки и контент | FAQ появляется только после useEffect |
| Видимые проверяемые факты совпадают с JSON-LD | Скрытые лицензии, выдуманный рейтинг, один @id для разных сущностей |

| Контент для человека и поисковика одинаков | Cloaking, массовые покупные упоминания «для LLM» |
| Прямой CTA и отдельное измерение установки | Обещание 100% трекинга через ping/редирект |
| Настоящие переводы и hreflang | Пустые локали с canonical на RU |

## Проверка гипотез и выпуск

Согласовать семантическое ядро и три приоритетных запроса: текущий список в [исследовании](../seo-research-2026.md) — гипотезы спроса. Для каждого запроса: задача пользователя → одна основная страница → полезный ответ → CTA → визит с кликом → установка. Не обещать отдельный поисковый rich result за FAQ-разметку.

Перед выпуском: `npm run lint`, `npm run typecheck`, `npm run build -- --webpack`, `npm run check:seo`. Повторить build/check с согласованным SITE_URL и SITE_INDEXING_ENABLED=true; preview — false. Нужны также публичные HTTP-проверки, URL Inspection и Lighthouse mobile ≥85. Production не считается запущенным по локальной сборке.

После запуска: baseline; день 28 — индексация и ошибки; день 90 — запросы, клики, конверсия; день 180 — цели. GSC AI-трафик включён в общий Web-отчёт: не обещать отдельный AI Overviews отчёт. Источник: [Google](https://developers.google.com/search/docs/appearance/ai-features).

ИИ-мониторинг ежемесячно: фиксированные 25 запросов из исследования, язык, регион, движок/модель, web-режим, дата; 3 прогона, сохранять ответ и cited URL. Считать отдельно упоминания, ссылки на домен и корректность фактов. Это операционный мониторинг, не гарантия статистической значимости.

ASO: после выдачи доступов сверить название, описание, категории, скриншоты, локали и ссылки обеих карточек; измерять store listing conversion отдельно от web CTA. Платные Ads требуют отдельного задания и бюджета. Наличие llms.txt, JSON-LD или разрешённого OAI-AdsBot не означает запуска рекламы или одобрения финансового продукта: [OpenAI Docs](https://developers.openai.com/api/docs/bots).

## Протокол проверки реализации · 26.10.2026

- ESLint и TypeScript: успешно.
- Next.js webpack build: успешно отдельно с выключенной и включённой индексацией; все 12 контентных страниц статические.
- `check:seo`: успешно для обоих режимов; проверены HTML, metadata, canonical, наличие JSON-LD, ссылки, OG PNG, sitemap/robots, платформы, четыре QR независимым декодером.
- Сборка потребовала исполнения вне sandbox: внутри Next.js не смог прочитать результат дочернего TypeScript `--showConfig`; исходный `tsc --noEmit` проходил.
- Публичный домен/CDN, Lighthouse, реальные установки, SEO-позиции и AI-цитаты не проверены. Это приёмка кода, а не завершение экономических KPI или всего MVP.
